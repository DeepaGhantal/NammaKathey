# 📖 NammaKathey (ನಮ್ಮ ಕಥೆ)

**NammaKathey** ("Our Story") is a modern Android application designed to inspire children through personalized storytelling. By leveraging the power of **Google Gemini AI**, the app creates unique adventures centered around the user's name, set against the beautiful cultural backdrop of Karnataka, India.

## ✨ Features
- **Personalized Hero:** Users input their name to become the protagonist of the story.
- **AI-Driven Narratives:** Uses **Gemini 2.0 Flash** for lightning-fast, creative, and child-friendly story generation.
- **Cultural Rooting:** Stories are specifically prompted to include themes from Karnataka (e.g., Mysore Palace, Hampi, Western Ghats).
- **Modern UI:** Built entirely with **Jetpack Compose** for a smooth, responsive user experience.
- **Secure Architecture:** Implements industry-standard API key management using Gradle's `BuildConfig`.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose
- **AI Integration:** Google Generative AI SDK (Gemini API)
- **Dependency Injection:** Hilt
- **Asynchronous Programming:** Coroutines & Flow
